# 人物属性与装备菜单合并

- 保留属性、技能蓝图的设计器布局和控制器。原生窗口增加左上角三页页签，Overlay 两个快捷按钮打开同一窗口的对应页。
- 装备页按配置槽位显示图标和名称，悬停显示穿戴效果。右侧展示背包选中的装备，兼容槽位可切换，已有装备在新装备上方。
- 背包选中可装备物品时打开人物菜单并切到装备页。背包和人物菜单各自关闭，沿用此前游戏内菜单输入分流。
- 效果读取已保存随机词条或固定 GE 配置。装备和卸下仍提交现有服务端请求。
- 执行装备 UI 自动化，读取实际蓝图父类，在隔离 PIE 验证页签、选中对比和共同显示。

Overlay 旧属性、技能打开与关闭的执行分支已经移除。人物窗口持有页签状态和输入注册，内嵌属性及技能页的独立注册停用。关闭窗口或更换 HUD 时解除注册。离开技能页时取消等待装配。背包独立注册，并在用户显式点击装备时打开第二页。
