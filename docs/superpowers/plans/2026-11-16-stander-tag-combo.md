# Stander Tag 连招实施

1. 以真实 Stander 左键输入和武器组作为回归入口，检查三段蒙太奇次序、按住屏蔽、单次缓存和换装失效。
2. 在 Avatar 上维护一份 Tag 转移配置和接续凭证。ASC 路由按下输入，权威端解析已授予的 Spec，两条 GA 前端以真实蒙太奇结束通知交接。
3. 保留现有 DA 和时间轴。出生旧连段接入共享 Timeline 任务，装备三段仍使用自己的 ActionTag 和配置。
4. 在临时联机世界授予两套开发用 LocalPredicted GA，逐段记录客户端预播、服务器激活、拒绝、预测键依赖和清理结果。正式游戏不授予对照能力。
5. 编译并运行玩家输入、正式连招、时间轴、弹反和装备回归。记录资产时序以及联机验证边界。
