# 技能图玩法扩展首版

用户已批准按“能力覆盖表 → 传播原位调参 → Forked并发分裂 → 更多选敌与条件”推进。本轮只扩展同一图、配置、共享动作及属性第四页工作台，不接掉落/消耗/存档，不重写原GA前端。

## 行为合同

- 传播节点应用后可直接修改总投递上限、逐跳等待、搜索半径、衰减；Forked还可修改层数、分支数及串行兼容/并发模式。编辑只影响下一次施法，保留稳定节点身份、原费用和动画事件。
- 旧Forked配置缺省继续串行FIFO；工作台新建Forked默认并发。并发模式在真实命中并等待配置延迟后，从该历史命中点同时发射最多N颗弹体；每颗有独立回执和资源租约。同一原生命只结算一次外部载荷，整根共享去重、总生成和并发额度；等待并发位不重置总预算。
- 选敌首版支持原默认、最近、最远、最低生命比例；复用Actor/Mass查询、可见性和原生命令牌。同步查询节点可选择有限个目标，输出TargetFound与Completed。
- 条件首版支持“伤害是否击杀”和概率0..1门控；分别接受DamageResult与Origin，输出Passed/Rejected位置快照。条件本身不造成伤害、不激活旧GA。可继续串接选敌、范围状态等可信片段。
- UI支持从输出口追加新查询/条件节点，再选新节点修改参数、继续追加片段；服务器仍按真实载荷和有限/持续合同校验。准备、费用、生命校验及清理保护保持原规则。
- 覆盖表区分注册能力、实际目录观察、可改参数、可信片段、Actor/Mass/网络及测试证据，不把声明或历史报告当作本次全量验证。

## 验收

先观察旧版本对并发字段/原位参数/新节点的失败；修复后验证真实并发弹体、独立延迟、深度衰减、去重、预算背压、取消/来源退休、旧FIFO兼容；Actor与Mass选敌和条件分支；工作台草稿/应用/撤销/版本冻结；单机及远端真实第四页操作与施法。全量旧基线单列，最终用户PIE视觉验收。
