# 标准近战招式取消与怪物受击设计

玩家应能根据命中结果改变下一招，看到危险时能在许可窗口转入防御。怪物在短时间内允许被连续压制，到达上限后获得清晰可见的脱离机会。首期用默认剑盾、一个普通 Actor 怪和一个精英验证，随后接入 Mass 和其他武器。

## 现有入口

- 当前剑盾普攻按 Tag 选择三段，上一段自然完成后才可接续。时间轴已支持连续分段变速，`CancelInto` 和 `bInterruptible` 目前提供查询。两条 Stander 动作前端还依赖 Busy 和移动占用。增加取消行为时需要在实际输入路由执行一次有条件的交接。
- 默认剑盾第一段 Recovery 已是 0.10 秒，第三段命中后约 0.089 秒。第二段的接触后阶段仍约 0.73 秒，优先对其拆分 Release 与 Recovery。基线见 `Saved/GAAuthoring/StanderCombo/implementation/final-readback.json`，数值为资产配置。
- Actor 伤害路径会尝试播放 `Effects.HitReact`，并可通过伤害上下文对活体调用 `LaunchCharacter`。目前共享伤害服务对 Actor 只记提交尝试和死亡结果，对 Mass 可读伤害数值。攻击取消和脱离计数需要同一份可靠的权威接触结果。
- Mass 已有眩晕与取消攻击，Crowd 负责共享动画和复制。活体浮空、落地受控和硬直脱离需按实体另行接入。当前翻滚与世界减速有 Standalone 边界。

## 玩家动作与取消表

时间轴按 **前摇 → 接触/释放 → 后摇** 编排。压缩按段调参，保留动画的源接触位置、位移曲线依赖和唯一伤害入口。以 Attack1 为手感基准，先把 Attack2 接触后的释放和后摇试到约 0.05 + 0.10–0.14 动作秒。轻招原型的前摇以 0.12–0.20 动作秒为目标，重击或终结技可以留更长的动作承诺。等看清真实动作姿势与混出后再定值。

| 当前阶段 | 普攻、下一项攻击 GA | 翻滚、格挡 |
| --- | --- | --- |
| 前摇 | 一条预输入可缓存，等到允许窗口才消费 | 首版一般招不开放；可对个别轻招另行配置晚前摇防御取消 |
| 接触/释放 | 结算当段接触，等待该技能配置的最后必保事件结束 | 同步保护接触与最小释放；首版在释放结束开放 |
| 后摇 | 确认有效接触后，按白名单取消进下一段普攻或下一项攻击技能。原左键顺序接续也可走自然结束路径，含挥空的普通三段 | 命中和挥空均可按白名单取消进入防御 |
| 多段技、突进、终结技 | 用该招明确标注的可切出点；保留尚未执行的事件直到进入许可窗口 | 每招单独配置。首期格挡/翻滚自身结束后恢复原输入权限 |

保留 `RequestComboInput(FGameplayTag InputTag)` 与现有连招路由。将取消申请的公共参数也设为输入 Tag，由 ASC 根据当前授予、装备、步骤和白名单解析目标 Spec。时间轴按源动画位置判定窗口，取消规则引用目标动作 Tag 和接触条件。输入 Tag 表达按键，GA Tag 表达要切入的动作，命中确认和状态 Tag 表达是否有权接续。常用类别可做显式配置，不让父标签隐式放行整个技能族。

一个新输入最多缓存一个请求，绑定源施法、动画实例和装备代次。建议缓存 0.12–0.15 动作秒。相同时间点的主动选项先消费防御，再处理技能和普通接段；首版默认翻滚、格挡、技能、普攻的优先级。只在对应窗口生效。玩家被击、死亡、倒地、换装或切图时依照现有强制清理规则释放缓存。

### 权威端交接

1. ASC 输入路由先解析目标 Spec，验证源会话、窗口和取消条件，并预检查目标费用、冷却、空地、角色状态及武器身份。只在交易上下文中把旧动作持有的 Busy/移动占用识别为可交接资源，其它门禁照常检查。目的技能不可用时，当前动作和它的后摇继续。
2. 确认接续后关闭旧技能对未来接触/Notify 的入口，解绑旧任务并释放它自己的句柄。记录独立的取消原因。普通攻击向下一段提前衔接时消耗一次同链授权；切到格挡、翻滚或其他招时清空普攻的待接续段。
3. 在旧 GA 的收尾回调退出后，消费前一步保存的一次性取消许可，复核化身、装备代次和目标，再按原 GAS Spec 激活新动作。旧技能费用和已经完成的伤害按原规则结算，新技能正常 Commit 一次。晚到的目标失败应干净回到可移动状态。已经生成的独立效果按技能自己的寿命合同运行。
4. 排除两套蒙太奇播放器并行。旧动作只清其自身播放实例和移动占用。新动作实际开启翻滚或格挡窗口后才具备防御效果，提前输入不预送无敌或弹反。

前锋动作和释放后取消是首期方案。全程随时取消会弱化动作承诺，也会让无成本的假动作和重复弹反更难管控。需要这类风格时，可以用同一套窗口逐招开放。

## 权威命中与怪物表现

在已有 `Combat.CharacterStrike` / `AbilityDamageService` 通路上增加一次接触的结算回执。它关联施法和事件序号、目标生命、格挡或无效原因、实际伤害及是否致死。Actor 从自己消费伤害元属性的结算点回填，Mass 从实体伤害结算回填。不要用扇形命中、调用了 GE、播放了特效或事后读取一次血量代替权威确认。

- **玩家确认。** 默认只有实际结算的有效攻击能开放命中取消。挥空、无敌、被弹反或只触碰目标不会开攻击取消。击杀可开玩家的取消窗口；控制目标必须重新验证原生命且存活。多目标中任意一个有效目标可开放一个窗口，同一次挥击仍只交接一次。
- **轻硬直。** 普攻或轻技能常用 0.22–0.30 世界秒原型硬直。角色停止移动，当前可被打断的攻击与预警立即作废，恢复后重新决策。让命中后保留的释放和下一招前摇总长比硬直短约 0.03–0.06 秒，以形成可练习的接续余量。
- **浮空。** 仅指定挑飞招可以进入。Actor 使用受控的竖直位移，配合击飞、空中和落地动作。空中追击使用上限和衰减，首轮每轮最多一次挑飞、两次空中续击，总滞空上限建议 0.65–0.85 世界秒。脱离时等待安全落地；墙、天花板、台阶和房间边界要参与扫掠。
- **击退。** 留给结束攻击或挡开敌人的指定技能。沿击中方向施加受碰撞约束的小位移，便于下一招追上；例如首试 60–100 cm。命中技能可以分别配置轻硬直、浮空、击退，死亡冲量仍只属于击杀表现。
- **表现。** 优先用可重播的短受击和失衡动画，加少量命中闪光或音效。弹反眩晕继续使用原眩晕和星星。连段硬直有独立状态，避免每下普攻都显示眩晕星。

## 怪物脱离规则

服务端每个怪物生命保存一份连段压制预算。该目标受到第一下合格压制攻击时开始一轮，按有效接触次数、累计实际生命伤害和轮次持续时间记账。多玩家共用同一目标的预算，一次接触同一目标只记一次，多段技能只有独立合法的接触事件才记账。持续伤害默认不进预算。自然恢复后开启下一轮条件由配置处理。挥空和剧情无敌不消耗预算。

| 配置类型 | 建议原型规则 |
| --- | --- |
| 普通怪 | 5 次有效接触、约 40% 最大生命实际伤害、连续压制 1.3 世界秒，任一达到即脱离。伤害判据从第 3 次合格接触起启用，按普通剑盾的真实输出复验，避免第一下就用光控制预算。 |
| 精英 | 重要动作可有抗打断窗口。允许受控时首试 3 次、约 20% 最大生命或 0.8 世界秒，伤害判据从第 2 次接触起启用。浮空默认关闭。 |
| Boss | 只在明确的失衡或破防窗口允许轻硬直。浮空和击退逐招许可。首期可先沿用各 Boss 可中断阶段，姿态槽另评估。 |

触发脱离的这一击仍正常扣血。它结束或缩短现有连段受击，之后约 0.5–0.8 世界秒拒绝普通硬直、浮空和击退，并给短促且可读的恢复反馈。空中先进入脱离落地，免控至少覆盖落地后的短窗口。恢复后由 AI 重新选择攻击，敌方反击按本项目规则重新预警。普通连段免控不取消正独立运行的弹反眩晕、石化或其他 GE；此类强控是否被 Boss 抵抗，由各怪物的独立许可配置。

受击策略应在受管理的攻击伤害发起时写入上下文，旧 Actor 属性回调不再为该次伤害重复执行普通 HitReact/Launch。脱离期间也应阻止仍走旧通路的普通击退与受击中断，否则混合组队仍可能锁怪。旧技能伤害、显式强控和死亡冲量沿用已有通路。Actor 复用 ASC 标记、黑板、攻击代次和现有池生命周期；Mass 用同一阈值规则并将最少状态写入 Fragment/Crowd。Mass 先实现硬直和脱离，再做受碰撞和高度判定约束的击退/浮空，避免出现画面升空但地面命中语义不明。

## 开发与验收顺序

1. **动作基线。** 读回真实 `Attack1/2/3`、`GA_Block`、固有翻滚与一项挑飞/击退候选。目前的资产名称只说明候选身份，实际作用以动作事件与实测为准。先调剑盾 Attack2 并记录其实际接触、可取消和恢复三个时间点。
2. **取消窗口。** 在现有 ASC/Timeline 和 Stander Combo 入口实现共享接续动作，首批开放 `普攻 → 技能`、`普攻挥空 → 防御`、`技能后摇 → 翻滚/格挡`。使用现有 Tag 输入、费用、持有者和清理。失效时测试没有重复释放、残留移动占用、格挡 GE 或旧伤害。
3. **Actor 受击闭环。** 普通怪做到能连续命中、挑飞或推离，以及达到预算后脱离再出招。用一只精英验证霸体阶段和脱离反馈。覆盖空挥、部分格挡、致死、多目标、持续伤害、多人压制、重复事件及两次对象池生命。
4. **Mass 与多人。** 接入实体硬直、攻击代次和表现快照，再扩位移状态。双端验证单次权威伤害、接续请求、蒙太奇与目标反应。先保留现有权威普攻；客户端的动作预播与异步回滚在稳定后独立接入。现有 Standalone 翻滚/世界慢速在联机中需要分别验证与扩展。

这是设计建议。时间、伤害比例、次数和优先级适合用剑盾首轮 PIE 进行调试。
