# 元素技能移植清单第二轮

续批见[元素技能移植清单第三轮](ga-elemental-porting-cloud-catalysts.md)。

上一轮 8 个技能已接入。本轮继续处理有独立战斗用途、能复用统一图和现有权威运行服务的机制。依据是 Larian 对水面、冻结、导电、状态条件、地表操作和自身移动的机制拆分。配方、命名、表现资产及实时数值沿用本项目自己的制作方式。[上一轮清单](ga-elemental-porting-roadmap.md) · [Larian 技能制作](https://docs.larian.com/Skill_creation) · [地表转换](https://docs.larian.com/Osiris/API/TransformSurfaceAtPosition)

| 顺序 | 可移植 GA | 应拆分的核心逻辑 |
| --- | --- | --- |
| 1 | 水纹浅滩 | 地面选点 → 创建有限潮地 → 接触者获得潮湿。地块类型、范围、寿命和成功端口独立。 |
| 2 | 凝潮冻土 | 查找同层自有潮地 → 转换为霜地。来源、结果和搜索距离可独立修改，沿用原地块大小及到期。 |
| 3 | 雷沼通电 | 查找同层自有潮地 → 转为通电地块 → 通过属性服务对接触敌人施加雷状态。转换和接触使用不同阶段。 |
| 4 | 霜壳回收 | 消耗一块符合范围和归属的临时霜地 → 成功后给予施法者护盾。消耗条件、护盾量和时长独立。 |
| 5 | 沼息回收 | 消耗一块符合范围和归属的临时毒地 → 成功后按有限节拍治疗自身。消耗条件、次数、间隔和治疗量独立。 |
| 6 | 潮痕两相 | 范围查询 → 对每个实际敌人检查当前状态 → 潮湿分支雷伤，其余目标火伤。条件、两条独立伤害分支、范围和表现可分别重组。 |
| 7 | 焰落突进 | 服务器用现有地面位移检查路线 → 取得实际停止位置 → 放置临时熔岩。位移、落点和地块独立，原有房间与碰撞限制仍适用。若无法复用安全地面判定，保留此项并解释阻塞。 |

## 对已有组合的处理

- 水变毒可用现有地表转换把来源设为潮地、结果设为毒地。冰面融化同样可组合为霜地转潮地。
- 地表引燃、驱散、弹射、分裂、周期领域、目标标记和原地延时爆炸沿用现有配方。新增等级、队列或装备扩展继续走各自既有入口。
- 实体蒸汽云、永久地图地表、队友治疗和复活、目标交换与召唤物灌注需要单独的世界层、队伍或角色复用合同。它们不属于这次沿现有图快速接入的候选。[Larian 地面与云层](https://docs.larian.com/AI_grid_panel)

## 交付顺序

1. 对潮地和通电地实现服务器接触与租约清理，保留原地表编号。验证 Actor、Mass、地块转化、所有权和生命隔离。
2. 接入两种地表消耗和回馈。逐个验证空放不产生收益、同层最近地块选择、独立卡片及取消。
3. 接入两相伤害和安全地面位移。核对筛选后的两路各自结算、范围同步、位移受阻时的实际落点及来源失效。
4. 在第四页用免费试装和真实 T 键进行组合。以当前 Editor 构建、目录卡片编译、实际行为和全项目自动化为证，另记录带渲染的 PIE 检查情况。
