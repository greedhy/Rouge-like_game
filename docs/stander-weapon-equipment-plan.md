# Stander 武器装备与技能组开发计划

2026-11-04。用户授权完整盘点、按已有流程制作所有适合战斗的动作GA、真实武器装备与换装技能替换，并持续执行到完成或遇到无法自行解决的阻塞。

## 交付合同

1. 每个动作都进入用途清单：攻击/施法/防御/位移作为技能或技能阶段；Idle/Run/Start/End/JumpFall/受击等绑定对应动画状态，不伪造为伤害技能。源素材保留。
2. 覆盖01至11武器动作组；模型缺失或无实体武器的组依据实际盘点明确映射，不伪称独立模型存在。每个可用战斗动作都有配置、技能身份、描述、图标与验证记录。
3. 装备使用现有背包实例、DT_Equipment、EquipmentComponent和PlayerState ASC。武器技能组引用由物品定义解析，不用第二套物品身份。换装交易成功后切换能力、模型与移动动画；取消旧技能的蒙太奇、延迟伤害和投射物归属按明确生命周期处理。
4. 旧武器能力按其授予句柄回收，不清空所有ASC能力；非武器能力保留。冷却不因重新装备同类武器刷新。初始六槽有默认搭配，超过六个技能全部授予并提供可选技能列表；不能只制作隐藏而无法使用的资产。
5. Actor/Mass共用目标筛选、墙/房间/楼层约束；近战、远程、区域技能各自匹配真实动作和命中时序。保留已实现死亡冲量链。
6. 保存与恢复复用物品实例和装备快照，重新初始化不得重复授予；失败换装保持原装备与能力组一致。外观同步不依赖远端拥有完整ASC技能表。
