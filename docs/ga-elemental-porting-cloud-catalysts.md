# 元素技能移植清单第三轮

本轮承接前两轮的临时地表与元素状态。新增地面和云层之间的转化、活地块供能，以及消耗状态才触发的连锁。按表中顺序登记和验收，互不依赖的节点可并行实现。所有技能沿用统一图、一次 GAS 提交、第四页试装及真实 T 键，阶段、条件与效果各自暴露给服务器配方编译器。[第二轮清单](ga-elemental-porting-terrain-chains.md) · [Larian 地表和云层变换](https://docs.larian.com/Osiris/API/TransformSurfaceAtPosition) · [状态及地表技能属性](https://docs.larian.com/Skill_creation)

| 顺序 | 可移植 GA | 核心逻辑与可独立修改项 |
| --- | --- | --- |
| 1 | 升潮化雾 | 选同层自有潮地 → 转为雾云 → 进入云体积的敌人触发水状态。搜索范围、来源和结果、地块租约、云接触各自独立。 |
| 2 | 雾凝清池 | 选自有雾云 → 回到地面的潮地。云源种类、产物和范围分开编辑，原尺寸和到期保留。 |
| 3 | 雷雾环生 | 选自有雾云 → 变成通电云 → 在云层体积应用雷状态。地表和云的空间层及接触种类独立处理。 |
| 4 | 旋风驱雾 | 选点移除同层自有临时雾云，成功位置触发后继。搜索范围、云类和清除成功边可以单独组装。 |
| 5 | 雷地借势 | 按有限时序查询当前位置附近的自有通电地。从该地块中心发出攻击，脉冲期间每次重新验证活地块。供能半径、地块种类、次数、间隔和伤害可调。 |
| 6 | 霜地借势 | 查询附近活着的自有霜地 → 在地块附近施加控制。可改地块种类、搜索半径、控制范围和时长，操作不消耗地块。 |
| 7 | 熔印裂爆 | 选灼热敌人 → 成功消耗灼热 → 从原目标中心发出范围爆发。选敌、消耗条件、范围、结算元素和伤害独立。 |
| 8 | 雷印传递 | 选并消耗导电印记 → 由原目标处接续有限传播，对邻近敌人结算。印记筛选和消耗、传播半径、上限与结算分开。 |

## 接入与验收

1. 云层由同一临时世界租约控制，按服务器判断接触。验证离地目标、相邻楼层、同层外地块、当前来源生命、保留到期时刻、地面驱散和云驱散互不误伤。
2. 验证借势每次按准确落点及活地块结算，跨技能切换后有效，撤掉供能地块会停止后续脉冲。单独试装更换供能源、节拍或实际效果。
3. 验证消耗节点只对匹配的真实生命成功，空放没有爆发。一个技能提供精确的状态局部分支，另一个验证有限范围传播。
4. 构建编辑器并回归旧图、Actor/Mass、目录和实际输入。表现读回与带渲染的 PIE 分别记录。

同类型投递、元素替换和既有地表变体继续使用改装卡。永久地图层、复活、友军组队状态、主动交换两个角色位置及召唤物灌注属于不同的授权、网络或生命周期合同。 [Larian 地面与云层](https://docs.larian.com/AI_grid_panel)
