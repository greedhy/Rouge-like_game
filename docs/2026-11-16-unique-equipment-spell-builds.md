# 第三批暗金：法术系列与近战周身特效

本批将法师的技能装备扩展到奥术范围与引导连锁，并让两件剑盾暗金在实际挥击时显示周身效果。分类与制作入口见[暗金与套装开发流程](unique-equipment-production-workflow.md)。

选型参考了三个公开的历史版本实例。

- 星陨头冠让陨石落到更多位置，并改变施放节奏。本项目让广域法袍改变整个实装范围系列的覆盖，奇点兜帽提供单技能集中伤害的路线。 [《暗黑 IV》1.3–1.5 官方补丁](https://news.blizzard.com/en-us/article/24140806/diablo-iv-patch-notes-1-3-1-5)
- Axial Conduit 让连锁闪电在围绕玩家与追踪敌人之间切换，并消耗法力。分雷戒选择索敌和目标数的取舍，基础倍率降低，沿用闪电引导的每周期费用。 [《暗黑 IV》1.5.0 官方补丁](https://news.blizzard.com/en-us/article/24123440/diablo-iv-1-5-0-patch-notes)
- 荒野套装让旋风斩带出尘卷风。霜旋战盔和日炎踏靴采用类似的周身视觉反馈，特效随原接触动作播放。 [《暗黑 III》荒野胸甲官方页](https://us.diablo3.blizzard.com/en-us/item/cuirass-of-the-wastes-Unique_Chest_Set_01_p2)

| ID / 装备 | 槽位 | 技能效果与代价 |
|---|---|---|
| `UniqueArcaneHorizonRobe` 广域法袍 | 护甲 | 奥术新星、奥术碎片半径 ×1.40，基础及持续伤害 ×0.80，护甲 ×0.75 |
| `UniqueSingularityHood` 奇点兜帽 | 头盔 | 奥术新星半径 ×0.80、基础及持续伤害 ×1.45，最大法力 ×0.80 |
| `UniqueForkstormRing` 分雷戒 | 戒指 | 闪电引导二次索敌半径 ×1.22，额外连锁 2 个目标，每个目标的基础伤害 ×0.72，法力恢复 ×0.75 |
| `UniqueFrostWakeHelm` 霜旋战盔 | 头盔 | 剑盾环斩（默认键 1）转为水系伤害，基础伤害 ×1.60，脚下寒霜 0.9 秒，护甲 ×0.72 |
| `UniqueSolarStepBoots` 日炎踏靴 | 鞋子 | 剑盾突进（默认键 2）转为火焰，基础伤害 ×1.50，脚下火环 0.8 秒，护甲 ×0.85，最大法力 ×0.80 |

**折空仪式**由广域法袍和奇点兜帽组成。法袍的伤害倍率由 0.80 改为 1.00。奥术新星同时受到兜帽规则，半径为原来的 1.12 倍，伤害为 1.45 倍。奥术碎片保留半径 1.40 倍，伤害回到原值。分雷戒可按现有左右戒指规则各穿一枚，额外目标数相加，半径和伤害因子相乘。

霜旋战盔与雷铸战盔竞争同一头盔槽，避免两种元素转换同时作用于环斩。两件新的近战装备对应不同技能，可同时装备。周身特效在有效接触动作开始时出现，挥空也有效。装备上的额外 Niagara 负责表现，伤害仍由原接触动作计算。

资产接入后使用开发控制台 `Equipment.SpawnUniques`，在较开阔的场地生成目录中的固定暗金 Soul。按 E 拾取后等到背包状态更新再穿戴。元数据在 `/Game/Equipment/DT_Equipment`，平衡数值在 `/Game/Equipment/Unique/CT_UniqueEquipmentStats`，选择器与 Niagara 引用在各自 GE。

| 相关回归 | 88/88 通过。真实新星验证额外范围、费用、齐套和拆套。雷链验证二次目标、实际周期参数、费用与取消。真实资产测试验证系列第二成员的参数和近战 Niagara 引用 |

| 主工程自动化 | 装备测试 32/32 通过，其中暗金测试 16/16。全项目 460/466 通过。失败项为原有 Timeline 目录校验、格挡窗口、剑盾输入交接、各武器格挡输入、恶魔双阶段、蘑菇怪双阶段 |
| 主工程拾取 | `L_RoguelikeRun` 单人 PIE 中通过 `Equipment.SpawnUniques` 生成 14/14 个 Soul。五件新品均显示近身提示，经实际拾取和装备请求进入对应槽位。霜旋战盔替换奇点兜帽后，兜帽以原实例返回背包 |

报告位于 `Saved/Automation/UniqueEquipment`。隔离工程报告在 `Batch3Sandbox`，主工程报告在 `Batch3Main`，包含 `Author.json`、`Idempotent.json`、`Verify.json`、`FullTests/index.json` 和 `Pickup.json`。`Author.json` 记录两张表的备份路径。

拾取测试在无渲染的单人 PIE 中调用 E 键绑定所用的拾取请求。周身特效的画面与远端表现仍待有渲染的联机 PIE 验收，重点检查挥空、随身跟随和卸装后下一次动作。
