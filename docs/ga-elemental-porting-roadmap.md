# 元素技能移植清单

续批见[元素技能移植清单第二轮](ga-elemental-porting-terrain-chains.md)。

本清单以《神界：原罪 2》中可辨认、可在本项目实时战斗中独立组合的机制为单位。官方工具将状态、选敌、范围、投递和地表动作分别定义。项目使用自己的技能身份、素材、数值和实时结算。依据为 [Larian 技能制作](https://docs.larian.com/Skill_creation)、[状态应用](https://docs.larian.com/Osiris/API/ApplyStatus)、[地表转化](https://docs.larian.com/Osiris/API/TransformSurfaceAtPosition)。

## 已覆盖与可直接组合的机制

润泽雨幕、炽焰涌爆、雷鸣骤击、寒晶爆发、沼蚀毒床、熔沼引燃、霜锋潮、潮印放电、涡流涤地、狭线裂霜、风压散流与灼印迸火已接入。现有目录也有元素弹体、穿透、弹跳、分裂、持续领域、陷阱、屏障与状态控制。相同的投递与元素变化优先组合已有节点或改装卡，单独的 GA 保留给具有新玩法闭环的能力。

| 可复用的参考机制 | 本项目的基础技能或改装 |
| --- | --- |
| 直射、连跳、分裂、扇射、穿透 | 火焰箭、寒霜扇射、穿云雷球。「逐个弹跳」「同时分裂」更换传播方式，元素卡独立改变伤害和暴露。 |
| 瞬发圆形、锥形、直线和向外扩张冲击 | 雷鸣骤击、风压散流、狭线裂霜、霜锋潮。范围形状、命中上限、朝向和元素由各阶段处理。 |
| 雨幕、有限领域、周期脉冲和到期爆发 | 润泽雨幕、雷狱结界、脉冲领域。周期、持续时间、控制和到期时的后继可以单独改装。 |
| 状态前置、命中联动、消耗状态和地表反应 | 潮印放电、灼印迸火、狭线裂霜、熔沼引燃、涡流涤地。已有筛选、条件、消耗和效果端口可复用。 |
| 屏障、石化、缓速、限次恢复 | 奥术护盾、凝滞力场、迟缓印记和回流卡。费用先结算，状态和资源交给相应节点。 |

## 接下来的开发顺序

| 顺序 | 适合移植的 GA | 核心逻辑及可独立改装位置 | 状态 |
| --- | --- | --- | --- |
| 1 | 潮息复苏 | 自身定位 → 有限恢复节拍 → 资源恢复。分别编辑脉冲次数、间隔、每次生命恢复量和后继。 | 已接入第四页 |
| 2 | 霜甲净化 | 自身状态精确清除 → 独立屏障。状态种类、护盾容量、时长和成功后分支各自配置。 | 已接入第四页 |
| 3 | 寒封熔地 | 查找当前生命持有的临时熔岩 → 验证同层和归属 → 转为霜地。原始和结果类别、搜索半径、成功位置独立。 | 已接入第四页 |
| 4 | 腐化霜地 | 用同一转化策略把临时霜地变为毒地。地块位置、实际尺寸、归属与截止时间由原租约提供。 | 已接入第四页 |
| 5 | 蒸汽冷凝 | 定点选带蒸汽的活目标 → 消耗匹配状态 → 施加水元素。选敌、前置状态、状态匹配和结果元素独立。 | 已接入第四页 |
| 6 | 导电回充 | 定点选带导电的目标 → 消耗匹配状态 → 回收法力。筛选、人数上限、消耗条件、回收量独立。 | 已接入第四页 |
| 7 | 雷印迟爆 | 选中带感电的目标 → 记录其位置 → 有限延时 → 在旧位置重新查目标 → 雷伤。状态筛选、引信、范围、伤害各自可换。 | 已接入第四页 |
| 8 | 霜晶阵雨 | 独立安排多个落点 → 单点间隔 → 每点重新选敌 → 冰伤和表现。点数、分布范围、间隔、单点半径和元素可调。 | 已接入第四页 |

## 适用边界

当前世界地表层负责临时地块的归属、碰撞接触、Actor／Mass 效果与到期。地图永久地形写入、真实蒸汽云层与地表的双向转换需要独立的层权限、空中接触和层复制。队伍治疗、复活、交换玩家位置、召唤物灌注等列入支持体系的单独入口，先建立真实队伍、召唤归属、死亡复用或移动同步合同。当前可复用的自身治疗与净化已列在本清单。Larian 把地表和云作为不同的转换层，并为友方、亡灵和道具指定独立条件。[地表与云](https://docs.larian.com/Osiris/API/TransformSurfaceAtPosition) · [目标条件](https://docs.larian.com/Skill_creation)

交付沿用第四页免费试装与真实 T 键。各批在本地 main 开发，发布试装前验证节点端口、实际行为、来源身份、生命周期和旧配方。特效及双端视觉验收独立记录。

## 验证结果

- UE 5.8 Development Editor 构建成功。工作台共 56 个技能、80 张独立可编译卡片，底层目录共 108 个类版本。
- 真实 T 键验证了恢复节拍、精确净化和护盾、毒地到熔岩再到霜地和藤地、蒸汽冷凝、导电回充、雷印锁点及霜晶落点。独立用例验证地表归属和跨 Run 隔离、原租约到期、Mass 重叠冰爆引发冻结，以及标记目标回收之后雷击仍在原位置结算。
- 项目自动化共 1088 项，1087 项通过。唯一失败为既有 `test_25d.UnifiedGA.Catalog.AllConfigurationAssets`，报告列出九个无法解析蒙太奇的旧 Stander 时间轴。结果位于 `Saved/GAAuthoring/ElementalRoadmapWave/Accepted/index.json`。
- Niagara 的实际画面、时间点与双端表现仍待 PIE 人工验收。
