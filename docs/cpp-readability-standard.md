# C++ 可读性规范

本次整理只涉及项目 Source 中的 C++，不修改 Python、资源资产或运行规则。

## 格式

根目录 `.clang-format` 是统一配置：4空格缩进，Allman花括号，120列参考宽度；函数、if/else、循环和lambda展开，不把多条语句挤在一行。不重排include、不拆分字符串、不自动改写注释段落。资源路径、反射宏及generated.h的包含顺序保持原样。

可使用Visual Studio自带的clang-format，通过 `clang-format -i --style=file <文件>` 格式化。不要格式化Intermediate、生成代码或第三方插件。

## 注释

每个业务cpp/h注明主要调用链：引擎/蓝图/输入/网络入口 → 本模块主要函数 → 下游模块或输出。区分声明接口、运行实现、测试夹具和编辑器探针，不能把include关系当成运行时调用关系。

函数注释应说明作用，必要时写明权威端要求、输入含义、返回失败条件和状态影响。函数内重点解释事务提交、异步回调、生命周期清理、对象池复用、去重和边界校验；不逐行翻译赋值语句，不仅把函数名换成中文。

调用链和注释应与代码一起更新。对蓝图或委托间接调用，不虚构唯一调用者。现有准确注释应保留，避免重复堆叠。
